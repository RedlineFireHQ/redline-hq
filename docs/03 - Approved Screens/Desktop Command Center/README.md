# Desktop Command Center

**Version:** 1.0

**Status:** APPROVED

---

## Purpose

Provide chiefs, officers, and administrators with an immediate understanding of the department's operational readiness.

This is the primary dashboard for the desktop/web application.

---

## Approved Layout

- Sidebar Navigation
- Redline Readiness
- Today's Mission
- Operational Status
- My Tasks
- Department Alerts
- Quick Actions
- Apparatus Status
- Inventory Snapshot
- Weather
- Activity Feed

---

## Design Decisions

- Firefighter image remains in the Redline Readiness card.
- Apparatus cards display:
  - Status
  - Last Checked Date
  - Last Checked Time
  - Checked By
- Inventory Snapshot remains on the dashboard.
- Weather remains in the lower-right corner.
- Mobile Home Screen will NOT use this layout.
- Use ONLY approved Redline HQ logos and branding.
